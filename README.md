# arbo-graph

Core de dados e validação para testar previsão espaço-temporal de dengue por Região
Administrativa do DF (grafos, Chronos-2), comparável ao baseline RF/XGBoost do
[Arbovirose-Dengue](https://github.com/Roger-Quinelato/Arbovirose-Dengue).

O código vem de `driveHugging/arbo-graph/`, onde ficou incubado no repositório de origem.
A migração chega por pull request. Plano: `driveHugging/PLANO_REPO_NOVO.md` no repositório de origem.
Nenhum dado é versionado aqui.
